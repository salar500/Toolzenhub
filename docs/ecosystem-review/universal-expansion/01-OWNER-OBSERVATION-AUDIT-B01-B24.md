# 01. Owner observation audit, B01 to B24

Each owner observation is a research input, not a verified defect. "Finding" says what was actually checked. Classes: **V** verified (observed in the repository or on the live preview), **P** public evidence (secondary sources, doc 00), **I** inference (reasoned from V), **H** hypothesis, **U** unknown. Disposition uses the rulebook 12.7 verdicts (A approved planning candidate, B needs validation, C future, D rejected or merge). Scores and ranks for new tools are in doc 03.
