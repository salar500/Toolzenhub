## Permutation behaviour (verified by tests in Phase 3)

| Permutation | Expected difference in the pack |
| --- | --- |
| Same task, role empty vs "QA lead" | an "About me" context line appears; nothing else changes |
| Beginner vs Senior | Beginner adds the explanation requirement and check and moves a multi default to standard; Senior adds trade-offs, risks, rejected alternative; standard default becomes detailed |
| Short vs Multi | Short: no stages, two refinements; Multi: every stage plus Final review |
| Product chosen vs none | AI product section names it with its dated official summary; prompts unchanged (provider-neutral) |
| Essential missing | `[add: …]`, listed in missing, closing line asks the AI to ask |
| Conflict entered | listed under "Check this first"; prompts keep both answers verbatim |
| Project context given (brief style) | fenced block after the goal, once |
| Consistency sheet given (media) | one "Keep the same" line in the master prompt and every stage prompt |
| Same input twice | identical pack (determinism) |
