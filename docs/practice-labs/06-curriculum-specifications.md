# 06. Curriculum and lesson specifications

## 1. Scope of this document

**Lesson-level specification** covers the paths of waves W1 to W5, the ones the next development stage builds first:

- SQL (remaining content)
- Manual Software Testing
- Test Design Techniques
- API Testing
- Playwright
- Git and GitHub
- JavaScript Fundamentals

For each lesson it gives the title, the slug, the objective, and the practice with its check type.

For W6 to W9 paths, the modules are fixed in [05](05-learning-path-catalogue.md). Their lessons are written in the **Requirements** step of that wave, using the same template (section 9). That step is part of the approved sequence, not a new planning round.

Check types:

| Code | Check |
|---|---|
| RS | Result-set comparison (SQL) |
| ST | Structured answer (fields, choices, order) |
| RB | Deterministic rubric (writing labs) |
| BH | Bug found in ShopLite (seeded-bug id) |
| HT | HTTP request or response match (mock API) |
| LO | Locator resolves to the intended element |
| CR | Code checked by tests or static rules |
| GS | Git state matches the goal graph |
| Q | Quiz (multiple choice, or predict-the-output) |

Every lesson also gets the template sections from [10](10-content-quality-standard.md).

**Interview Practice module (`interview`).** 1 page, 25 checked questions (mixed Q and RS), drawn from all levels, with explanations.

**Dataset rule.** Each new table is defined once in `dataset.js` (or a per-project setup array), and expected results are generated by Python `sqlite3` (the independent oracle), exactly as the lab's `reviewed` block describes.

**SQL completion criterion.** 24 lessons, 6 projects and 1 interview module are published. The path page "Still to come" list is removed. The SQL status becomes **complete**.

## 9. Lesson template for W6 to W9 (Requirements step)

For each module listed in [05](05-learning-path-catalogue.md), the Requirements step produces a table like those above. Each row needs:

- slug,
- title,
- one measurable objective (an action verb: write, explain, find, fix),
- practice with its check type,
- dataset or engine dependency.

It also produces:

- 2 to 6 lessons per module;
- 1 to 3 projects per path;
- one Interview module.

**Acceptance:** the table exists and is reviewed against [10](10-content-quality-standard.md) before any lesson is written.
